# 🏛️ Life Empire - Rise & Consequence

> Un jeu de gestion incrémentale où chaque décision économique a des conséquences morales et environnementales mesurables.

## 🎮 Concept

**Life Empire** est un "capitalisme conscient" jouable : tu bâtis un empire économique tout en gérant l'impact de tes décisions sur le monde.

### Principe de jeu

- Démarrer comme simple entrepreneur
- Bâtir un empire économique sans détruire le monde... ou en assumant de le faire
- Chaque décision a des effets visibles : richesse, pollution, moralité, influence, stabilité sociale

### 3 Styles de jeu

1. **Capitaliste pur** : Croissance rapide, mais instabilité mondiale
2. **Éco-leader** : Croissance lente, mais réputation solide
3. **Mafieux** : Profits massifs à court terme, risque de sanctions et effondrement

## 🧠 Innovation : IA Narrative Adaptative

- Génération d'événements dynamiques en fonction de tes choix
- Chaque joueur vit une histoire différente avec des arcs narratifs uniques
- L'IA te confronte à tes contradictions et dilemmes éthiques
- Exemples :
  - Investir dans le pétrole → mouvement écologiste mondial contre toi
  - Licenciements massifs → grèves et baisse de productivité
  - Corruption → enquêtes médiatiques et scandales

## 📊 Systèmes de jeu

### Ressources principales

- **💰 Richesse** : Capital, revenus, investissements
- **🌍 Impact environnemental** : Pollution, ressources naturelles, climat
- **⚖️ Moralité** : Réputation publique, éthique des affaires
- **📢 Influence médiatique** : Contrôle narratif, opinion publique
- **🏛️ Stabilité sociale** : Satisfaction employés, paix sociale

### Mécaniques de progression

- **Idle/Incremental** : Revenus automatiques, upgrades permanents
- **Arbre de décisions** : Choix moraux avec conséquences à long terme
- **Événements dynamiques** : Crises, opportunités, scandales générés par IA
- **Industries débloquables** : Agriculture → Industrie → Tech → Spatial
- **Ères historiques** : Révolution industrielle → Ère numérique → Futur

## 💰 Monétisation

- **Pass "Visionnaire"** : Scénarios mondiaux (crise climatique, cyberguerre, IA rebelle)
- **Boosters stratégiques** : Accélération production, consultants IA premium
- **Publicités contextuelles** : Adaptées au style de jeu du joueur
- **Extensions thématiques** : "Ère spatiale", "Crise énergétique", "Révolution des IA"

## 🛠️ Stack technique

- **Frontend** : HTML5 + CSS3 + JavaScript (Vanilla ou React)
- **Game Engine** : Architecture modulaire custom
- **AI Backend** : Integration GPT API pour narration
- **Database** : LocalStorage (prototype) → Supabase/Firebase (production)
- **Deployment** : GitHub Pages / Netlify / Vercel
